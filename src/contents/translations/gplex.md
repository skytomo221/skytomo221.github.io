> **GPLEX について**
>
> Gardens Point LEX (gplex) は、
> 有限状態オートマトンに基づくスキャナを生成します。
> 生成されたオートマトンの状態数はデフォルトで最小化されており、
> テーブル圧縮のための多数のオプションが用意されています。
> デフォルトの圧縮方式は入力アルファベットのカーディナリティに応じて選択され、
> ほとんどの場合適切な結果が得られます。
> ただし、必要に応じてユーザーが動作を調整するための多数のオプションが用意されています。
>
> このツールは、開始状態スタックなど、多くの FLEX 拡張機能を実装しています。
>
> 生成されたスキャナは、
> Gardens Point Parser Generator (gppg) によって生成されたボトムアップ パーサと明確にインターフェースするように設計されています。
> ただし、gplex によって生成されたスキャナは、
> 手書きのパーサと COCO/R によって生成されたパーサの両方で正常に使用されています。

### I章 GPLEX の概要

#### 1 概要

この論文は、gplex 字句解析器生成器に関するドキュメントです。

Gardens Point LEX (gplex) は、
「LEX ライク」な仕様を受け入れ、
C# 出力ファイルを生成する字句解析器生成器です。
この実装は、以前の類似プログラムとコードもアルゴリズムも共有していません。
このツールは、LEX の POSIX 仕様全体を実装しようとはしていませんが、
Unicode のサポートなど、いくつかの領域では LEX を超えています。

gplex によって生成されるスキャナはスレッドセーフであり、
すべてのスキャナ状態はスキャナインスタンス内で保持されます。
従来の LEX でグローバルな変数は、スキャナオブジェクトのインスタンス変数です。
ほとんどの変数は、ゲッターのみを公開するプロパティを介してアクセスされます。

gplex の実装は、共通言語ランタイム (CLR) のバージョン 2.0 の機能を多用しています。
以前のバージョンのフレームワークで動作させる見込みはありません。

gplex は主に 2 つの方法で使用されます。
最も一般的なケースでは、スキャナは、
そのスキャナが動作するパーサーによって定義された特定の型を実装または拡張します。
また、パーサーから独立し、文字ストリームに対してパターンマッチングを実行するスキャナも作成できます。
この「スタンドアロン」ケースでは、
gplexツールは必要なスーパータイプ定義をスキャナのソースファイルに挿入します。

スキャナのコードは3つのソースから派生します。
スキャナのクラス構造、パターン認識エンジンの仕組み、入力ストリームのデコードとバッファリングを定義する不変コードがあります。
これらの部分は、「フレーム」ファイルと「バッファ」ファイルで定義され、
それぞれがgplex実行ファイルに埋め込まれたリソースです。

パターン認識を実行する有限状態マシンと、
各パターンが認識されたときに呼び出されるセマンティックアクションを定義するテーブルは、
フレームファイルのコードとインターリーブされます。
これらのテーブルは、ユーザーが指定した `*.lex` 入力ファイルからgplexによって作成されます。

最後に、ユーザー指定のコードを入力ファイルに埋め込むことができます。
これらのコードはすべて、メインのスキャナークラス定義に挿入されます。詳細はセクション3.2で説明します。
生成されたスキャナークラスは`partial`として宣言されているため、
ユーザーはLEX仕様とは別のC#ファイルでスキャナークラスのコードを指定することもできます。
入力ファイルの形式を確認したい場合は、このドキュメントのII章に直接進んでください。

##### 1.1 典型的な使用法

gplexスキャナを用いたシンプルで典型的なアプリケーションは、2つの部分から構成されます。
パーサーは/gplexオプション付きで呼び出されたgppgを使用して構築され、
スキャナはgplexを使用して構築されます。
パーサーオブジェクトは常に、
QUT.Gppg名前空間からインポートされたAbstractScanner型のプロパティ「Scanner」を持ちます（図3を参照）。
スキャナ仕様ファイルには、次の行が含まれます。

```lex
%using ParserNamespace
```

ここで、`ParserNamespace` は、パーサー仕様で定義されたパーサーモジュールの名前空間です。
アプリケーションの `Main` メソッドは、入力ストリームを開き、
図 1 のコードスニペットと同様のコードを使用して、スキャナーとパーサーオブジェクトを構築します。

図 1: Typical Main Program Structure

```cs
static void Main(string[] args)
{
  Stream file;
  // parse input args, and open input file
  Scanner scanner = new Scanner(file);
  Parser parser = new Parser(scanner);
  parser.Parse();
  // and so on ...
}
```
